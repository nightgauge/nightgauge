# go-test-uncached.txt — Go tests the local gate always runs with -count=1 (#3208).
#
# scripts/ci-local.sh runs `go test ./...` and `go test -race ./...` WITHOUT
# -count=1, so an unchanged package replays its last result from Go's test cache.
# The cache key covers the package's sources and dependencies, the flags, the
# toolchain, go.mod/go.sum, and every environment variable and file the TEST
# PROCESS itself reads through package os (Getenv, Open, Stat, Chdir). A binary
# found through exec.LookPath is stat'd, so replacing `git` or `bash` already
# invalidates the cache.
#
# Membership rule. A test belongs here when its result depends on something the
# cache cannot see:
#   - content a CHILD process reads that the test never opened or stat'd through
#     os (`exec.Command("bash", "scripts/x.sh")` reads x.sh in the child);
#   - files outside the module, the real worktree's git state, the network, or
#     the clock.
# A test that execs `git` only against a t.TempDir() repository stays cached, as
# does one that reads a script with os.ReadFile and runs a temp copy of it.
#
# Format: `<import path> <TopLevelTestName>`, one per line, with a reason.
# scripts/go-test-uncached.py runs them per package with -count=1 -run, and fails
# the gate when a listed test no longer exists, naming the entry.
